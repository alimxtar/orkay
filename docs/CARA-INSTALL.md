# Cara install Orkay

```text
ORKAY — aplikasi catatan keuangan pribadi
Gratis, tanpa iklan, tanpa akun, jalan offline. Datamu terenkripsi dan hanya tersimpan di perangkatmu sendiri.
==========================================================================================================

HP ANDROID  (file: Orkay-1.0.0.apk)
------------------------------------
1. Simpan file Orkay-1.0.0.apk ke HP (dari WhatsApp / Google Drive / kabel data).
2. Buka file tersebut. Jika muncul "Untuk keamanan, HP tidak diizinkan memasang aplikasi dari sumber ini",
   ketuk "Setelan" lalu aktifkan "Izinkan dari sumber ini", kemudian kembali dan ketuk "Instal".
3. Jika muncul peringatan Play Protect ("aplikasi tidak dikenal"), ketuk "Info selengkapnya" → "Tetap instal".
   (Peringatan ini muncul karena aplikasi tidak diunduh dari Play Store, bukan karena berbahaya.)
4. Buka Orkay dari daftar aplikasi.
Butuh Android 7.0 atau lebih baru.

LAPTOP / PC WINDOWS  (file: Orkay-Setup-1.0.0.exe)
--------------------------------------------------
1. Jalankan Orkay-Setup-1.0.0.exe.
2. Jika muncul layar biru "Windows protected your PC" (SmartScreen), klik "More info" → "Run anyway".
   (Muncul karena installer belum memakai sertifikat tanda tangan berbayar.)
3. Ikuti langkah instalasi. Ikon Orkay akan ada di Desktop dan Start Menu.
Butuh Windows 10/11 64-bit.

IPHONE / IPAD  (lewat link, tidak perlu file)
---------------------------------------------
1. Buka link Orkay di SAFARI (bukan Chrome/Instagram/WhatsApp in-app browser):
   https://GANTI-DENGAN-LINK-ORKAY
2. Ketuk tombol Bagikan (kotak dengan panah ke atas) di bawah layar.
3. Gulir lalu pilih "Tambahkan ke Layar Utama" / "Add to Home Screen" → "Tambah".
4. Buka Orkay dari ikon di Layar Utama (bukan dari Safari).
Setelah dibuka sekali, Orkay tetap jalan tanpa internet. Butuh iOS 16.4 atau lebih baru.
Untuk backup: Pengaturan → Unduh backup → pilih "Simpan ke File" (iCloud Drive).
Catatan: data di ikon Layar Utama terpisah dari data di Safari — selalu buka dari ikonnya.

PENTING DIBACA
--------------
• Saat pertama kali dibuka, kamu membuat KATA SANDI. Kata sandi ini mengenkripsi datamu dan
  TIDAK BISA DIPULIHKAN kalau lupa. Catat di tempat aman.
• Data tidak tersinkron antara HP dan laptop. Untuk memindahkan data:
  Pengaturan → Unduh backup (di perangkat lama) → Pengaturan → Impor (di perangkat baru).
• Kalau aplikasi dihapus, datanya ikut terhapus. Rajinlah membuat backup (Pengaturan → Unduh backup)
  dan simpan file backup di Google Drive / flashdisk. File backup juga terenkripsi.
• Bahasa Indonesia / English bisa diganti di Pengaturan.
```
